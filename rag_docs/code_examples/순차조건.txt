주제: 순차/조건 | 교육과정: 중학교 정보 | 난이도: 기초

핵심 문법: 변수, 입출력, if-elif-else, 비교·논리 연산자, 나머지 연산

[예제 1 - 홀수/짝수 판별]
number = int(input("숫자를 입력하세요: "))
if number % 2 == 0:
    print(number, "은(는) 짝수입니다.")
else:
    print(number, "은(는) 홀수입니다.")
설명: 입력받은 숫자를 2로 나눈 나머지로 홀짝을 판별하고 결과를 출력한다.

[예제 2 - 점수에 따른 학점 분류]
score = int(input("점수를 입력하세요: "))
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
print("학점:", grade)
설명: 점수 범위를 순서대로 비교해 해당 학점 문자를 결정하고 출력한다.

[예제 3 - 두 수 중 최댓값]
a = int(input("첫 번째 수: "))
b = int(input("두 번째 수: "))
if a > b:
    bigger = a
else:
    bigger = b
print("더 큰 수:", bigger)
설명: 두 정수를 비교하여 더 큰 값을 찾아 출력한다.

[예제 4 - 양수/음수/0 분류]
n = int(input("정수 입력: "))
if n > 0:
    print("양수")
elif n < 0:
    print("음수")
else:
    print("0")
설명: 입력값의 부호를 판단해 세 가지 경우 중 하나를 출력한다.

학습 포인트:
- 변수에 값을 저장하고 사용하는 방법
- if / elif / else 조건 분기 구조
- 비교 연산자(>, <, >=, <=, ==, !=)와 나머지 연산자(%)
- 논리 연산자(and, or, not)로 복합 조건 표현
