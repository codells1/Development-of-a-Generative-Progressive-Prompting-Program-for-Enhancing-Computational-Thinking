주제: 반복문/리스트 | 교육과정: 중학교 정보 | 난이도: 초급

핵심 문법: for, while, range(), 리스트 순회, append(), 최댓값 탐색, 누적합

[예제 1 - 1부터 n까지 합계]
n = int(input("n을 입력하세요: "))
total = 0
for i in range(1, n + 1):
    total = total + i
print("1부터", n, "까지의 합:", total)
설명: range()로 1부터 n까지 반복하며 total에 누적해 합계를 구한다.

[예제 2 - 리스트에서 최댓값 탐색]
scores = [78, 92, 65, 88, 74]
max_score = scores[0]
for score in scores:
    if score > max_score:
        max_score = score
print("최고 점수:", max_score)
설명: 첫 번째 원소를 기준으로 시작해 더 큰 값을 찾을 때마다 max_score를 갱신한다.

[예제 3 - 사용자 입력으로 리스트 만들기]
numbers = []
for i in range(5):
    num = int(input(f"{i+1}번째 숫자: "))
    numbers.append(num)
print("입력한 숫자들:", numbers)
설명: 빈 리스트에 5번 입력받은 값을 append()로 추가해 리스트를 완성한다.

[예제 4 - while로 카운트다운]
count = 5
while count > 0:
    print(count)
    count = count - 1
print("발사!")
설명: count가 0이 될 때까지 while 반복문으로 카운트다운 후 종료 메시지를 출력한다.

학습 포인트:
- for + range()로 정해진 횟수 반복
- 리스트 생성, 접근, append()로 원소 추가
- while 조건 반복과 탈출 조건
- 누적 변수 패턴 (total = total + i)
- 최댓값 갱신 패턴 (if 새값 > 현재최댓값)
