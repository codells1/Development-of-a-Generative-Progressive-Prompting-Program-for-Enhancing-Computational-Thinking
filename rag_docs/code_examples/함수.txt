주제: 함수 | 교육과정: 중학교~고등학교 정보 | 난이도: 중급

핵심 문법: def, 매개변수, return, 판별 함수, 알고리즘 캡슐화

[예제 1 - 절댓값 계산 함수]
def absolute(n):
    if n >= 0:
        return n
    else:
        return -n

print(absolute(5))
print(absolute(-3))
설명: 숫자를 받아 양수로 변환해 반환하는 순수 함수. 조건 분기로 부호를 처리한다.

[예제 2 - 소수 판별 함수]
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, n):
        if n % i == 0:
            return False
    return True

for num in range(2, 20):
    if is_prime(num):
        print(num, end=" ")
설명: 2부터 n-1까지 나누어 떨어지는 수가 없으면 소수로 판정하는 함수.

[예제 3 - 리스트 평균 계산]
def calc_average(numbers):
    total = 0
    for n in numbers:
        total += n
    return total / len(numbers)

scores = [85, 90, 78, 92, 88]
avg = calc_average(scores)
print(f"평균: {avg:.1f}")
설명: 리스트를 받아 합계를 구하고 원소 수로 나눠 평균을 반환한다.

[예제 4 - 별 출력 함수]
def print_stars(count):
    for i in range(1, count + 1):
        print("*" * i)

print_stars(4)
설명: 매개변수로 줄 수를 받아 별을 증가하며 출력하는 패턴 함수.

학습 포인트:
- def로 함수 정의, 매개변수와 return 이해
- 동일 로직을 재사용 가능한 단위로 캡슐화
- 판별 함수(bool 반환)와 계산 함수(값 반환) 구분
- 함수 호출로 복잡한 알고리즘을 읽기 쉽게 표현
