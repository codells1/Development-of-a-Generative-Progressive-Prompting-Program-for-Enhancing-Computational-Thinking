주제: 알고리즘 | 교육과정: 고등학교 정보 | 난이도: 심화

핵심 문법: 버블정렬, 선택정렬, 순차탐색, 이진탐색, 2차원 리스트

[예제 1 - 버블 정렬]
data = [64, 34, 25, 12, 22, 11, 90]
n = len(data)
for i in range(n - 1):
    for j in range(n - 1 - i):
        if data[j] > data[j + 1]:
            data[j], data[j + 1] = data[j + 1], data[j]
print("정렬 결과:", data)
설명: 인접한 두 원소를 비교·교환하며 가장 큰 값을 뒤로 밀어내는 정렬 알고리즘.

[예제 2 - 선택 정렬]
data = [29, 10, 14, 37, 13]
for i in range(len(data)):
    min_idx = i
    for j in range(i + 1, len(data)):
        if data[j] < data[min_idx]:
            min_idx = j
    data[i], data[min_idx] = data[min_idx], data[i]
print("정렬 결과:", data)
설명: 미정렬 구간에서 최솟값을 찾아 맨 앞으로 이동시키는 정렬 알고리즘.

[예제 3 - 순차 탐색]
def linear_search(lst, target):
    for i in range(len(lst)):
        if lst[i] == target:
            return i
    return -1

nums = [3, 7, 1, 9, 4, 6]
idx = linear_search(nums, 9)
print("9의 위치:", idx)
설명: 처음부터 순서대로 비교해 목표값의 인덱스를 반환하는 탐색 함수.

[예제 4 - 이진 탐색]
def binary_search(lst, target):
    left, right = 0, len(lst) - 1
    while left <= right:
        mid = (left + right) // 2
        if lst[mid] == target:
            return mid
        elif lst[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

sorted_nums = [1, 3, 5, 7, 9, 11, 13]
print("7의 위치:", binary_search(sorted_nums, 7))
설명: 정렬된 리스트에서 중간값과 비교해 탐색 범위를 절반씩 줄이는 탐색 알고리즘.

학습 포인트:
- 이중 반복문으로 정렬 알고리즘 구현
- 인덱스 변수(min_idx, left, right)의 역할 추적
- 순차탐색 O(n) vs 이진탐색 O(log n) 비교
- 2차원 리스트: matrix = [[1,2],[3,4]], matrix[row][col]로 접근
