CT 요소: 분해 (Decomposition)
problem_index: 0
난이도: 매우쉬움

== 개요 ==
코드를 기능 단위로 분리하고, 각 단위의 독립적 역할을 파악하는 능력을 측정한다.
전체 코드를 한 번에 이해하려 하지 않고, 역할별로 나누어 파악하는 것이 핵심이다.

== 질문 패턴 ==
- 이 코드를 역할에 따라 나눈다면 몇 단계인가?
- 이 함수가 담당하는 역할은 무엇인가?
- 코드에서 입력을 담당하는 부분은 어느 줄인가?
- 이 코드를 기능별로 나누면 가장 적절한 것은?
- 다음 코드에서 처리(계산) 역할을 하는 부분은?

== 인지 조작 ==
전체 코드를 기능 단위(입력 / 처리 / 출력)로 분리하고
각 단위가 독립적으로 어떤 역할을 맡는지 파악한다.
함수 이름, 변수 이름, 연산 종류를 단서로 역할을 추론한다.

== 오답 설계 원칙 ==
- 역할이 비슷한 두 블록을 하나로 합쳐서 단계 수를 줄인 오답 제시
- 단계 수를 1개 틀리게 제시 (3단계 → 2단계 또는 5단계)
- 입력과 처리를 하나로 묶거나, 처리와 출력을 하나로 묶은 오답 제시
- 실제 역할과 다른 이름의 단계 제시 (예: 처리 대신 "정렬"로 표현)

== 난이도 기준 ==
- 함수 이름이 직관적이고 블록 수가 2~3개인 코드 사용
- 들여쓰기와 빈 줄로 역할 구분이 눈에 보이는 코드
- 복잡한 알고리즘 없이 입력→처리→출력 흐름이 명확한 코드

== 예시 문제 1 ==
코드:
  name = input("이름을 입력하세요: ")
  greeting = "안녕하세요, " + name + "!"
  print(greeting)

Q: 위 코드를 역할별로 나눈다면 가장 적절한 것은?
A. 입력 / 처리 / 출력  (정답)
B. 입력 / 출력
C. 변수 선언 / 출력
D. 입력 / 계산 / 저장 / 출력
정답: A
해설: 첫 줄은 사용자 입력, 둘째 줄은 문자열 합치기(처리), 셋째 줄은 결과 출력이다. 세 역할로 분해된다.

== 예시 문제 2 ==
코드:
  scores = [85, 92, 78, 90, 88]
  total = sum(scores)
  average = total / len(scores)
  print("평균:", average)

Q: 위 코드에서 처리(계산) 역할을 담당하는 줄은?
A. 1번째 줄 (scores 정의)
B. 2번째, 3번째 줄  (정답)
C. 4번째 줄 (print)
D. 1번째, 4번째 줄
정답: B
해설: 합계와 평균을 계산하는 2~3번째 줄이 처리 단계이다. 1번째는 데이터 준비, 4번째는 출력이다.
