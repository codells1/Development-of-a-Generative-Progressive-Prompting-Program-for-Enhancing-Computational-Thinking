CT 요소: 추상화 (Abstraction)
problem_index: 2
난이도: 보통

== 개요 ==
구체적 값이나 구현 방법이 아닌, 변수·함수가 표현하는 개념·역할을 파악하는 능력을 측정한다.
"이 변수에 어떤 값이 들어있나"가 아니라 "이 변수가 무엇을 의미하나"를 묻는 것이 핵심이다.

== 질문 패턴 ==
- 변수 {이름}이 나타내는 것은?
- 함수 {이름}의 역할을 가장 잘 설명한 것은?
- 왜 이 변수의 이름을 {이름}으로 지었을까?
- 이 코드에서 {변수명}이 추상화하는 개념은?
- 함수의 반환값이 의미하는 것은?

== 인지 조작 ==
구체적 값(숫자, 문자열)이나 자료형에 집중하지 않고,
변수명·함수명·연산 맥락을 종합하여
코드가 표현하려는 추상적 개념(역할, 의미)을 파악한다.

== 오답 설계 원칙 ==
- 자료형으로 오답 유도 (예: "정수형 변수")
- 구체적 값을 역할로 혼동 (예: "100을 저장하는 변수")
- 비슷한 이름의 다른 변수와 혼동
- 부분 역할을 전체 역할로 혼동

== 난이도 기준 ==
- 약어 또는 범용 이름(result, temp, count) 사용
- 변수의 의미를 맥락에서만 파악 가능한 코드
- 함수 이름이 동작을 직접 드러내지 않는 코드

== 예시 문제 1 ==
코드:
  def process(scores):
      total = 0
      for s in scores:
          total = total + s
      result = total / len(scores)
      return result

Q: 변수 result가 나타내는 것은?
A. 점수 리스트의 길이
B. 모든 점수의 합계
C. 모든 점수의 평균  (정답)
D. 가장 높은 점수
정답: C
해설: total에 합계를 누적한 뒤 len(scores)로 나누므로 result는 평균을 나타낸다.

== 예시 문제 2 ==
코드:
  def check(word, letter):
      count = 0
      for c in word:
          if c == letter:
              count = count + 1
      return count

Q: 변수 count가 추상화하는 개념은?
A. 단어의 전체 길이
B. 특정 글자의 등장 횟수  (정답)
C. 반복 실행 횟수
D. 마지막으로 비교한 글자의 위치
정답: B
해설: c == letter 조건이 참일 때만 count가 증가하므로, count는 letter가 word 안에 나온 횟수를 나타낸다.
