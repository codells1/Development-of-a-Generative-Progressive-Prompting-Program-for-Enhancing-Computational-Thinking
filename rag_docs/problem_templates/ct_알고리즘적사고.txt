CT 요소: 알고리즘적사고 (Algorithmic Thinking)
problem_index: 3
난이도: 어려움

== 개요 ==
코드를 줄 단위로 순서대로 실행하며 변수 상태를 추적하는 능력을 측정한다.
조건문과 반복문이 결합된 코드에서 최종 변수 값이나 출력 결과를 정확히 예측하는 것이 핵심이다.

== 질문 패턴 ==
- n번 반복 후 변수 {이름}의 값은?
- 조건 {조건식}이 참일 때 실행되는 블록은?
- 이 코드를 실행한 최종 출력은?
- 다음 코드 실행 후 변수들의 상태로 올바른 것은?
- 코드를 단계별로 실행했을 때 {n}번째 출력은?

== 인지 조작 ==
코드를 한 줄씩 순서대로 실행하며
각 반복 회차에서 모든 변수의 값을 직접 추적한다.
조건문 분기, 변수 갱신, 반복 종료 조건을 놓치지 않는다.

== 오답 설계 원칙 ==
- off-by-one: 반복을 1회 더 또는 덜 실행한 결과 제시
- 조건을 반대로 적용한 결과 제시 (if → else 결과)
- 중간 회차의 변수값을 최종값으로 제시
- 변수 초기값을 잘못 설정한 결과 제시

== 난이도 기준 ==
- 조건문이 포함된 반복문
- 변수 3개 이내
- 반복 5회 이내
- range() 의 두 번째 인자에 주의가 필요한 코드

== 예시 문제 1 ==
코드:
  x = 0
  for i in range(1, 4):
      x = x + i
  print(x)

Q: 위 코드 실행 후 출력되는 값은?
A. 3
B. 6  (정답)
C. 4
D. 9
정답: B
해설: i=1→x=1, i=2→x=3, i=3→x=6. range(1,4)는 1,2,3 세 번 반복이므로 최종 x=6이다.

== 예시 문제 2 ==
코드:
  result = 1
  n = 4
  for i in range(1, n + 1):
      if i % 2 == 0:
          result = result * i

Q: 코드 실행 후 result의 값은?
A. 24
B. 8  (정답)
C. 6
D. 4
정답: B
해설: i=1(홀수→건너뜀), i=2(짝수→result=2), i=3(홀수→건너뜀), i=4(짝수→result=8). 짝수 2와 4만 곱해 result=8이다.
