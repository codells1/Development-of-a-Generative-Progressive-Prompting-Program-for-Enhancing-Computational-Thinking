CT 요소: 통합 (Integration)
problem_index: 4
난이도: 매우어려움

== 개요 ==
분해·패턴인식·추상화·알고리즘적사고를 종합하여 코드 전체의 목적을 도출하는 능력을 측정한다.
각 부분의 역할을 이해한 뒤 전체 흐름을 보고 "이 코드는 무엇을 하는가"를 판단하는 것이 핵심이다.

== 질문 패턴 ==
- 이 코드가 해결하는 문제는?
- 이 코드의 최종 목적으로 가장 적절한 것은?
- 어떤 상황에서 이 코드를 사용하면 유용한가?
- 이 함수의 전체 동작을 가장 잘 설명한 것은?
- 이 코드를 한 문장으로 요약한다면?

== 인지 조작 ==
단순히 한 줄을 읽는 것이 아니라,
분해(역할 구조), 패턴인식(반복 패턴), 추상화(변수 의미),
알고리즘적사고(실행 흐름)를 모두 종합하여
코드가 해결하려는 상위 목적을 추론한다.

== 오답 설계 원칙 ==
- 중간 과정을 전체 목적으로 혼동하도록 유도
- 비슷하지만 목적이 다른 알고리즘 제시 (최댓값 vs 최솟값, 정렬 vs 검색)
- 코드의 일부 기능만 설명하는 오답 제시
- 비슷한 자료구조를 다루지만 목적이 다른 선택지 제시

== 난이도 기준 ==
- 함수명·변수명에 목적이 드러나지 않는 코드 (예: func, process, do_work)
- 전체 흐름을 읽어야만 목적을 파악할 수 있는 코드
- 여러 CT 요소를 함께 사용하는 복합 코드

== 예시 문제 1 ==
코드:
  def func(numbers):
      best = numbers[0]
      for n in numbers:
          if n > best:
              best = n
      return best

Q: 위 함수의 목적으로 가장 적절한 것은?
A. 리스트를 오름차순으로 정렬한다
B. 리스트에서 가장 큰 값을 찾는다  (정답)
C. 리스트의 평균을 계산한다
D. 리스트에서 중복 값을 제거한다
정답: B
해설: best를 첫 요소로 초기화한 뒤, 더 큰 값을 만날 때마다 best를 갱신한다. 최종 반환값은 가장 큰 값이다.

== 예시 문제 2 ==
코드:
  def mystery(data):
      seen = []
      output = []
      for item in data:
          if item not in seen:
              seen.append(item)
              output.append(item)
      return output

Q: 위 함수가 해결하는 문제는?
A. 리스트를 정렬한다
B. 리스트에서 특정 값을 검색한다
C. 리스트에서 중복을 제거하고 처음 등장한 순서를 유지한다  (정답)
D. 리스트의 합계를 구한다
정답: C
해설: seen에 이미 있는 값은 output에 추가하지 않으므로, 중복 없이 처음 등장 순서를 유지한 리스트를 반환한다.
