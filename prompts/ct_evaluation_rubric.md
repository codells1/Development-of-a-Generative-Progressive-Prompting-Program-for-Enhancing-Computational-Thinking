# CT 평가 루브릭 (상중하 점수 + 서술형 피드백) — 채점기 지시용 요약

학생의 채팅 발화(질문·요청·진술)만 근거로 평정한다. 퀴즈 정답 여부는 보지 않는다.
전체 출처: `prompts/ct_feedback_rubric.md`.

## 요소별 상·중·하 (없으면 N/A)

세션 전반에서 전형적으로 나타난 수준으로 매긴다. 관련 발화가 전혀 없으면 **N/A**.
'결과·정답만 요구'처럼 회피적 발화가 있으면 **하**. 중↔상 분기: "한 줄씩/표면 묘사=중", "목적·이유·구조 통합=상".

| 요소 | 하 | 중 | 상 |
|---|---|---|---|
| 문제분해 | 안 나누고 통째 요청 | 나누나 순서·연결 없음 | 분해 + 관계·처리 순서 |
| 용어사용 | 일상어만 | 용어 오용·혼동 | 용어가 모두 정확 |
| 추상화 | 전부 동등 취급 | 핵심만 지목 | 핵심·보조 대비 + 핵심 초점 |
| 실행흐름 | 결과만 요청 | 순서 대략 서술 | 순차·선택·반복 구조 명시 |
| 자료표현 | 데이터 언급 없음 | 형태만 일상 언급 | 타입·자료구조 명시 |
| 동작파악 | 그대로 수용 | 실행 결과만 질문 | 왜·어떻게(원리·인과) 질문 |
| 자기해결\* | 정답만 요구 | 힌트 후 정답 요청 회귀 | 힌트로 자기 접근·다음 단계 제안 |

\* 자기해결은 메타인지 축 — CT 총점과 분리 집계.

## 서술형 피드백 규칙 (학생용, 3~5문장)

1. 격려적 도입 1문장. 2. 잘한 점(상/중 1~2개)을 학생이 실제 한 발화에 근거해 칭찬.
3. 더 해보면 좋을 점(하/중 1~2개)을 "다음엔 ~해보자"는 다음 행동 제안으로. 4. (선택) 따뜻한 마무리.

- 약점은 최대 1~2개만. 과제 중심("이번에 ~를 잘했어/다음엔 ~해보자"), 능력·서열 칭찬 금지.
- 글에 상중하 라벨을 직접 박지 말고 행동으로 서술. 정답은 알려주지 않는다(무엇을 살펴볼지만 제안).
- N/A 요소는 약점으로 지적하지 말 것(권유는 가능).
- 모두 하/N/A면 과제 관련 노력을 짚고 다음 단계 하나만. 모두 상이면 한 단계 더 깊은 도전 제안.
- 톤: 중·고생 눈높이의 친근하고 격려적인 2인칭, 성장 중심.

## 출력 형식

아래 JSON 객체 하나만 출력한다(마크다운·설명 문장 금지). 각 요소 값은 "상"·"중"·"하" 또는 "N/A".

```json
{
  "문제분해": "중", "용어사용": "중", "추상화": "하", "실행흐름": "상",
  "자료표현": "하", "동작파악": "중", "패턴인식": "N/A",
  "자기해결": "중",
  "weak_ct": "자료표현",
  "feedback": "학생용 서술형 피드백 3~5문장 (위 규칙대로)"
}
```
